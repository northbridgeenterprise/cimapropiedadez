# Cima Propiedades — sitio web

Sitio estático (HTML + CSS, sin dependencias). Se puede publicar tal cual en GitHub Pages, Netlify o Cloudflare Pages.

## Archivos

| Archivo | Qué es |
|---|---|
| `index.html` | Portada |
| `vender-casa-*.html` | Páginas por situación (Infonavit, herencia, gravamen, mal estado) |
| `aviso-de-privacidad.html` | Aviso de privacidad |
| `404.html` | Página para enlaces rotos |
| `estilos.css` | Estilos compartidos por todas las páginas |
| `og-imagen.png` | Imagen que aparece al compartir el enlace en WhatsApp o Facebook |
| `icono-180.png` | Ícono al guardar el sitio en la pantalla del celular |
